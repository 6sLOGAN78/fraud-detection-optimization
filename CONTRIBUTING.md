# Contributing to IEEE-CIS Fraud Detection System

Thank you for contributing to this project!

---

## 📜 Development Guidelines

1. **Code Quality**: All new code must include type hints and docstrings.
2. **Formatting**: Format code using `ruff` and ensure line lengths stay under 120 characters.
3. **Unit Tests**: Add unit tests in `tests/` for any new feature or bug fix.
4. **Pull Requests**: Ensure all 295+ unit tests pass before submitting PR:
   ```bash
   pytest tests/
   ```
